拼豆鏡子 —— 把攝影機畫面即時變成拼豆圖（Windows / Mac）

【Windows】
1. 插上 USB 攝影機（筆電內建鏡頭也可以）
2. 點兩下 PindouMirror.exe（或「拼豆鏡子.exe」），會直接全螢幕顯示
   - 第一次開啟較慢（約 5～10 秒）
   - 若出現「Windows 已保護您的電腦」：點「其他資訊 → 仍要執行」
3. 若顯示找不到攝影機：「設定 → 隱私權與安全性 → 相機」打開「讓桌面應用程式存取您的相機」
4. 螢幕直放時：「設定 → 系統 → 顯示器 → 顯示方向」改成「直向」，畫面就會滿版

【Mac（M1 以後的 Apple 晶片）】
1. 解壓縮 PindouMirror-mac.zip，把 PindouMirror（拼豆鏡子）拖進「應用程式」資料夾
2. 第一次打開時，macOS 會說「無法驗證開發者」（這個 App 沒有向 Apple 付費簽署）：
   - 到「系統設定 → 隱私權與安全性」，往下找到「仍要打開」按一下，再輸入密碼確認
   - 只有第一次需要這樣做
3. 跳出「拼豆鏡子想要取用相機」時按「允許」，畫面幾秒內就會出現
   - 如果不小心按了不允許：「系統設定 → 隱私權與安全性 → 相機」把拼豆鏡子打開
4. 螢幕直放時：「系統設定 → 顯示器 → 旋轉」選 90°，畫面就會滿版

【按鍵】（Windows、Mac 相同）
  Esc / Q   離開
  + / -     豆子變多 / 變少（更清楚 / 更像拼豆）
  B         切換拼豆品牌：Perler（103 色）/ MARD（291 色）
  M         鏡像開關（預設開，像照鏡子）
  R         畫面旋轉 90 度（不方便改系統設定時用）
  C         切換攝影機（有多台攝影機時）
  F         全螢幕開關
  L         自動補光開關（展場偏暗時讓顏色不灰）
  N / P     下一個 / 上一個濾鏡
  A         濾鏡自動輪播開關（預設開，每 30 秒換一個）
  空白鍵    倒數 5 秒拍照（觀眾也可以對鏡頭張開手掌比 5）
  H         顯示 / 隱藏操作說明

【濾鏡】（每 30 秒自動輪播，畫面上方會顯示目前的濾鏡名稱）
  原色 → 浪漫曇阿鵝（藍白冷色）→ 沙漠好奇浣熊（紅棕暖色）
  每個濾鏡都只用真實拼豆色號中的一組顏色，所以畫面永遠是「真的拼得出來」的拼豆圖。

【拍照】
  觀眾對鏡頭張開手掌「比 5」約 1 秒 → 畫面中間倒數 5、4、3、2、1 → 拍照（畫面閃一下）。
  工作人員也可以按空白鍵開始倒數。
  照片存在：Windows＝exe 旁邊的 photos 資料夾；Mac＝~/Library/Application Support/拼豆鏡子/photos
  拍完後左下角顯示「照片已存檔」；設定好上傳位置後，會改顯示 QR code 讓觀眾掃描下載。
  手勢辨識需要畫面中看得到整隻手，光線太暗時可能偵測不到，可以改按空白鍵。

【螢幕】
  建議：Dell P2414Hb（23.8 吋、1920×1080）直放，Windows 顯示方向設成「直向」→ 畫面 1080×1920 滿版。
  預設 40 顆寬，在這台螢幕上每顆豆子約 5mm，跟真實拼豆差不多大。

【外框】
  拼豆畫面外面套著粉紅色外框（右下角有浪漫曇阿鵝）。
  螢幕比外框寬時，兩側會補上同樣的粉紅色。
  要換外框：把新的 GIF 取名 frame.gif 交給開發人員重新打包（中間需留透明窗格）。

設定會自動記住，下次開啟沿用：
  Windows：exe 旁邊的 pindou_settings.json
  Mac：~/Library/Application Support/拼豆鏡子/

若發生錯誤，會跳出提示並寫入 pindou_error.log（位置同上），請把這個檔案傳給開發人員。

【隱私】
畫面只在螢幕上即時顯示，不錄影、不存檔、不連網。
