拼豆鏡子 —— 把攝影機畫面即時變成拼豆圖（Windows / Mac）

【Windows】
1. 插上 USB 攝影機（筆電內建鏡頭也可以）
2. 點兩下 PindouMirror.exe（或「拼豆鏡子.exe」），會直接全螢幕顯示
   - 第一次開啟較慢（約 5～10 秒）
   - 若出現「Windows 已保護您的電腦」：點「其他資訊 → 仍要執行」
3. 若顯示找不到攝影機：「設定 → 隱私權與安全性 → 相機」打開「讓桌面應用程式存取您的相機」
4. 螢幕直放時：「設定 → 系統 → 顯示器 → 顯示方向」改成「直向」，畫面就會滿版

【Mac（M1 以後的 Apple 晶片）】
1. 解壓縮 PindouMirror-mac.zip，把 PindouMirror（拼豆鏡子）拖進「應用程式」資料夾
2. 第一次打開時，macOS 會說「無法驗證開發者」（這個 App 沒有向 Apple 付費簽署）：
   - 到「系統設定 → 隱私權與安全性」，往下找到「仍要打開」按一下，再輸入密碼確認
   - 只有第一次需要這樣做
3. 跳出「拼豆鏡子想要取用相機」時按「允許」，畫面幾秒內就會出現
   - 如果不小心按了不允許：「系統設定 → 隱私權與安全性 → 相機」把拼豆鏡子打開
4. 螢幕直放時：「系統設定 → 顯示器 → 旋轉」選 90°，畫面就會滿版

【按鍵】（Windows、Mac 相同）
  Esc / Q   離開
  + / -     豆子變多 / 變少（更清楚 / 更像拼豆）
  B         切換拼豆品牌：Perler（103 色）/ MARD（291 色）
  M         鏡像開關（預設開，像照鏡子）
  R         畫面旋轉 90 度（不方便改系統設定時用）
  C         切換攝影機（有多台攝影機時）
  F         全螢幕開關
  L         自動補光開關（展場偏暗時讓顏色不灰）
  H         顯示 / 隱藏操作說明

設定會自動記住，下次開啟沿用：
  Windows：exe 旁邊的 pindou_settings.json
  Mac：~/Library/Application Support/拼豆鏡子/

若發生錯誤，會跳出提示並寫入 pindou_error.log（位置同上），請把這個檔案傳給開發人員。

【隱私】
畫面只在螢幕上即時顯示，不錄影、不存檔、不連網。
